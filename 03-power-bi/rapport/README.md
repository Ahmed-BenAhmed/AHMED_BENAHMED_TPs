# TP Power BI - Ahmed Benahmed

Package Typst du rapport Power BI.

## Build

```bash
typst compile --root . report.typ build/tp_power_bi_ahmed_report.pdf
```

## Contenu

- `report.typ` : source Typst du rapport.
- `media/` : logos utilises par la page de garde.
- `figures/` : copies stables des captures d'ecran.
- `build/` : PDF compile.
