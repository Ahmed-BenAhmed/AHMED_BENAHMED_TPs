# TP SQL Server SSIS - Ahmed Benahmed

Package Typst du rapport SQL Server Integration Services.

## Build

```bash
typst compile --root . report.typ build/tp_sql_server_ssis_ahmed_report.pdf
```

## Contenu

- `report.typ` : source Typst du rapport.
- `media/` : logos utilises par la page de garde.
- `figures/` : copies stables des captures d'ecran.
- `build/` : PDF compile.
